Listador de Idades de Alunos 

Programa no terminal que lista idades de 1 até um valor máximo, filtrando apenas números pares ou ímpares, com limite de quantidade.

Como funciona
- O usuário define a idade máxima (deve ser maior que 0)
- O usuário define quantas idades quer visualizar
- Escolhe o filtro digitando "pares" ou "impares"/"ímpares"
- O programa percorre de 1 até a idade máxima e exibe apenas as idades que batem com o filtro escolhido
- Para automaticamente ao atingir a quantidade desejada
